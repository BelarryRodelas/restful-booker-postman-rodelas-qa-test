# Restful Booker API Testing
Postman API testing suite for Restful Booker, featuring automated CRUD operations, dynamic variable chaining, authentication, positive and negative test scenarios, and response validation.
This repository contains a Postman API testing suite developed as part of the Junior Tech Associate(QA) Technical Assessment.

## Project Overview
The project focuses on validating the functionality, reliability, and behavior of the Restful Booker API through a collection of automated API requests.

It demonstrates fundamental API testing practices, including authentication, CRUD operations, dynamic variable chaining, response validation, negative testing, and test data cleanup.

## Objectives
The primary objectives of this project are to:
* Validate API endpoints through positive and negative test scenarios.
* Implement authentication and token management.
* Demonstrate dynamic variable chaining between API requests.
* Validate HTTP status codes, response, structures, and specific payload values.
* Ensure proper handling of invalid requests and unauthorized access.

## Technology Stack
1. Postman - API testing and automation
2. TypeScript - Writing test scripts and assertions
3. REST API - Application interface under test
4. JSON - Request and response data
5. GitHub- Version Control and project hosting
